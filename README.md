# 🎨 Responsive Portfolio Website

A modern, fully responsive personal portfolio website built with **HTML5**, **CSS3**, and **Vanilla JavaScript**. Features dark/light mode, custom cursor, typing animation, scroll reveal effects, and a clean gradient UI — perfect for developers, designers, and freelancers.

![Portfolio Preview](https://images.unsplash.com/photo-1467232004584-a241de8bcf5d?w=1200&q=80)

---

## ✨ Features

- 🌈 **Modern Gradient UI** — Purple → Pink → Cyan theme
- 🌙 **Dark / Light Mode** — Toggle with `localStorage` persistence
- ⌨️ **Typing Animation** — Rotating hero text
- 🎯 **Custom Cursor** — Smooth follower dot (desktop only)
- 📊 **Animated Skill Bars** — Fill on scroll using `IntersectionObserver`
- 🎬 **Scroll Reveal** — Elements fade-in as you scroll
- 📱 **Fully Responsive** — Works on mobile, tablet & desktop
- 🍔 **Animated Mobile Menu** — Hamburger → slide-in drawer
- 🔝 **Scroll-to-Top Button** — Appears after scrolling
- 💌 **Contact Form** — Fake submit with loading animation
- 🔗 **Active Nav Highlight** — Auto-highlights current section
- ⚡ **Zero Dependencies** — Pure vanilla JS, no frameworks
